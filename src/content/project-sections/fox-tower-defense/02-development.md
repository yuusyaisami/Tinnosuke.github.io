## 実装テーマ

ゲーム性としてはタワーディフェンスですが、開発面では「どこを見れば次の判断ができるか」を明快にする UI 設計が主題でした。  
ゲームループが単調にならないように、敵の流れを視認しやすくすることも重視しています。

## 学んだこと

- プレイ中の情報量は多ければよいわけではない
- UI とゲーム進行のテンポはセットで調整する必要がある
- 早い段階で導線を絞ると、後半の調整がやりやすい
